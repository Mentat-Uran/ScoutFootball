- **Profit/Loss Simulation + Cumulative Trajectory + Difficulty Stratification (2026-07-13, Round 35):**
  1. Added `ProfitLossPoint` and `ProfitLossSimulationReport` dataclasses plus `compute_profit_loss_simulation()` in `backtests.py` — simulates flat-stake (1 unit each) and Kelly betting strategies on backtest predictions. Per match: argmax selects predicted outcome, `implied_odds = 1.0 / max(p, 1e-12)`, `flat_profit = (odds-1) if correct else -1.0`, `kelly_fraction = (p*odds - 1)/(odds - 1)` clamped to [0,1], `kelly_stake = kelly_fraction`, `kelly_profit = kelly_stake * flat_profit`. Tracks cumulative profit and drawdown (peak - current) for both strategies. Returns `win_rate`, `flat_roi` (total_flat_profit / total_flat_stake), `kelly_roi`, `max_flat_drawdown`, `max_kelly_drawdown`, `avg_confidence`, `assessment` (`profitable` >0.05 ROI, `breakeven`, `unprofitable` <-0.02), and a disclaimer. Caps `max_points` (default 500) but recomputes totals on the full dataset. Raises `ValueError` on missing probability columns.
  2. Added `TrajectoryPoint` and `CumulativeTrajectoryReport` dataclasses plus `compute_cumulative_trajectory()` in `backtests.py` — sorts by `match_date`, computes cumulative accuracy (via `np.cumsum` of correct flags), cumulative Brier, and cumulative profit (flat-stake). Rolling window (default 50, `min_periods=1`) computes rolling accuracy and Brier. Change point detection: flags indices where `abs(diff(rolling_accuracy[window-1:])) > change_threshold` (default 0.05). Trend assessment compares first-half vs second-half rolling accuracy: `improving` (later > earlier + 0.02), `degrading` (later < earlier - 0.02), `stable`, `insufficient_data` (<2*window matches). Returns `best_window_accuracy`/`worst_window_accuracy` (max/min of fully-populated rolling values). Empty DataFrame returns early with `insufficient_data` trend. Raises `ValueError` on missing probability columns.

Fine-grained bins via `pd.qcut` (falls back to `pd.cut` on duplicates) into `n_bins` (2–20) quantile bins. Per tier computes `n_matches`, `accuracy`, `brier`, `rps`, `log_loss` (when `exact_score_probability` present), `avg_confidence`, `calibration_gap` (avg_confidence - accuracy), and `assessment` (`strong` acc≥0.6, `average` acc≥0.4, `weak`). Reports `best_tier`/`worst_tier` by accuracy. Validates `0.0 < hard_threshold < easy_threshold < 1.0`. Raises `ValueError` on missing probability columns or invalid thresholds.
