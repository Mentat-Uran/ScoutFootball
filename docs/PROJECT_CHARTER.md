# ScoutFootball 项目章程

> 更新日期：2026-07-29。本文是项目定位的最高优先级文档；路线图、任务队列、README 和功能说明与本文冲突时，以本文为准。

## 1. 核心定位

ScoutFootball 是一个**本地优先、开放源代码、个人维护、非盈利**的足球分析与研究项目。

当前第一参考用途是：维护者在本机长期研究足球球员评分，包括明确研究问题、固定数据快照、角色内比较、baseline 与候选模型评估、不确定性、人工复核和可重放研究包。世界杯、招募、比赛准备、动作价值、互操作和战术工具是复用同一证据内核的场景或研究素材，不以扩大产品宽度为独立目标。具体专项边界和实施门禁见 [`PLAYER_RATING_RESEARCH_SYSTEM_PLAN.md`](PLAYER_RATING_RESEARCH_SYSTEM_PLAN.md)。

- **本地优先：** 核心数据、模型、工作区和导出默认在用户自己的设备上运行和保存；不要求账号、公共云或持续联网。
- **开放：** 仓库代码和项目文档按 [`LICENSE`](../LICENSE) 中的 MIT License 开放；协议、测试夹具和可合法再分发的样例应尽量保持可检查、可复现和可移植。
- **个人：** 第一服务对象是维护者本人以及具有相似需求的个人足球爱好者、独立分析者和研究学习者；社区可以使用、修改和贡献，但项目不承诺企业级支持、SLA 或按外部需求交付功能。
- **非盈利：** 项目不以收入、付费转化、市场份额、客户数量或融资为目标，不规划付费层、商业版、销售漏斗或专有功能墙。

“非盈利”约束的是本项目的维护方式和路线选择，不额外限制 MIT License 已授予的权利，也不能覆盖第三方数据、视频、商标或模型各自的许可条件。

## 2. 使用边界

| 对象 | 默认边界 |
| --- | --- |
| 仓库代码与文档 | 按 MIT License 使用、修改和分发 |
| 公开或合成样例 | 只有许可明确时才随仓库提供，并保留来源、署名和再分发条件 |
| 用户本地数据 | 由用户控制，默认不上传、不遥测、不集中收集 |
| 商业供应商数据 | 仅允许用户通过合法文件或授权 API 在本地使用；项目不抓取、转售或重新分发 |
| 本地训练产物与报告 | 继承输入许可和隐私边界；能够导出不代表能够公开发布 |

联网能力只能是明确触发、可关闭、可解释的适配器；断网时，核心浏览、研究、复核和导出路径应尽可能继续工作。任何遥测都必须默认关闭，并在启用前说明字段、目的、保存和删除方式。

## 3. 路线决策顺序

功能和研究按以下顺序取舍：

1. 修复真实性、安全、许可、隐私、数据损坏和不可恢复风险。
2. 完成维护者真实使用的足球工作流断点。
3. 提高来源完整性、可复现性、可解释性、离线能力和可移植性。
4. 降低单人维护成本、运行成本和长期复杂度。
5. 扩展可复用的开放协议、适配器、测试和研究基线。
6. 最后才考虑新页面、新模型或展示性功能。

厂商和同类项目调研用于理解方法、标准、缺陷和可复用接口，不用于寻找商业竞争、定价或获客机会。

## 4. 长期开发规则

- 路线图只表达**依赖关系、先后顺序、启动条件和退出门槛**，不设周、月、年份或完成期限。
- 后序方向只有在前序门槛成立时才启动；没有数据、许可、维护能力或实际用途时可以无限期暂停、跳过或停止。
- “长期”不等于必须完成全部设想。删除低价值能力、缩小范围和保留稳定旧方案都可以是正确结果。
- 同时进行的工作必须受单人维护能力约束；可靠性和真实工作流优先于研究探索。

## 5. 成功标准

项目成功主要体现为：

- 维护者能够在本机完成可重复的球员评分研究任务，并按需把结果用于球探、比赛准备或其他数据/模型研究；
- 关键结论能够回到合法来源、输入快照、转换、模型、证据和人工判断；
- 数据缺失、低覆盖、不确定性和失败状态不会被包装成确定事实；
- 项目可以离线恢复、迁移、重建和长期由个人理解与维护；
- 开放协议、文档、测试和合法样例能帮助其他个人复用或检验工作。

下载量、活跃用户、组织席位、收入、续费和商业部署数量不是项目 KPI。

## 6. 明确不走的方向

- SaaS、订阅、企业版、商业许可分层和销售驱动路线。
- 强制账号、默认云同步、默认遥测或集中持有用户敏感数据。
- 数据转售、绕过访问控制的抓取、版权视频托管或转会撮合。
- 医疗诊断、博彩交易、保证结果的预测和以模型替代人的最终判断。
- 为满足外部组织而承担与个人项目不相称的实时 SLA、定制交付和运维义务。

如果未来确实需要改变这些定位，必须由维护者明确决定，并先修改本章程，再调整路线图和实现；不能由某个功能、部署配置或外部需求默默改变项目性质。
